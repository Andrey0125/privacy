Политика конфиденциальности

Расширение: Яркий Директ (Chrome)

Дата: 26 мая 2026

1. Назначение расширения

Расширение добавляет в интерфейс Яндекс.Директ и Яндекс.Вордстат: визуализацию данных (полоски в ячейках таблиц отчётов), пресеты отчётов, частотный анализ слов по поисковым запросам, управление минус-словами, панель работы с площадками, инструменты для Wordstat и добавление условий фильтра через контекстное меню. Оно не собирает и не передаёт персональные данные пользователя.

2. Обрабатываемые данные

Хранилище в браузере (chrome.storage.local): на устройстве пользователя сохраняются только его настройки — привязка столбцов отчёта к цветовым группам, цвета групп, размеры панелей, состояние включения/выключения раскраски; списки минус-слов (стоп-слов) для частотного анализа; настройки панели Wordstat. Эти данные не отправляются на наши или сторонние серверы.

Синхронизация Chrome (chrome.storage.sync): при включённой синхронизации браузера могут сохраняться настройки включения/выключения модулей расширения (гистограммы, частотный анализ, Wordstat); списки пресетов отчётов и пометки об удалённых заводских пресетах — только для синхронизации между вашими устройствами через аккаунт Google, не на наши серверы.

Локальное хранилище страницы (localStorage): часть настроек гистограмм и панелей сохраняется в localStorage на домене Яндекс.Директ для быстрого доступа при работе с отчётами. Данные остаются в браузере пользователя.

Резервная копия настроек: по нажатию кнопки «Выгрузить настройки» в popup расширения пользователь может сохранить JSON-файл на свой компьютер. Загрузка выполняется только по явному выбору файла. Файл не передаётся на наши серверы.

Доступ к буферу обмена (clipboardRead): при нажатии пользователем на кнопку загрузки площадок из буфера в блоке «Анализ площадок» расширение считывает текстовый список площадок из буфера обмена, обрабатывает его локально в браузере и не передаёт ни в какие внешние сервисы. Чтение буфера выполняется только по явному действию пользователя и только на страницах Яндекс.Директ.

Контекстное меню (contextMenus): на страницах Яндекс.Директ доступен пункт «Яркий Директ: добавить в фильтр». По выбору пункта расширение отправляет сообщение только внутри браузера вашей же вкладке с Директом, чтобы заполнить фильтр отчёта; данные не отправляются на наши или сторонние серверы.

3. Доступ к страницам

Расширение действует только на страницах Яндекс.Директ (direct.yandex.ru, direct.yandex.com и поддомены) и Яндекс.Вордстат (wordstat.yandex.ru). Оно не читает и не передаёт содержимое страниц за пределы браузера.

4. Сторонние сервисы

Расширение не использует аналитику, рекламу и не подключает внешние скрипты. Никакие данные не передаются третьим лицам.

5. Изменения

Актуальная версия политики доступна по этой ссылке. При существенных изменениях дата обновления будет изменена.
