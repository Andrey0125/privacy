Политика конфиденциальности

Расширение: Яркий Директ (Chrome)

Дата: 2026

1. Назначение расширения

Расширение добавляет в интерфейс Яндекс.Директ: визуализацию данных (полоски в ячейках таблиц отчётов), частотный анализ слов по поисковым запросам и управление минус-словами. Оно не собирает и не передаёт персональные данные пользователя.

2. Обрабатываемые данные

Хранилище в браузере (chrome.storage.local): на устройстве пользователя сохраняются только его настройки — привязка столбцов отчёта к цветовым группам, цвета групп, размер окна настроек и состояние включения/выключения раскраски; список минус-слов (стоп-слов) для частотного анализа. Эти данные не отправляются на наши или сторонние серверы.

Синхронизация Chrome (chrome.storage.sync): при включённой синхронизации браузера могут сохраняться настройки включения/выключения модулей расширения (гистограммы, частотный анализ) — только для синхронизации между вашими устройствами через аккаунт Google, не на наши серверы.

Доступ к буферу обмена (clipboardRead): при нажатии пользователем на кнопку загрузки площадок из буфера в блоке «Площадки» расширение считывает текстовый список площадок из буфера обмена, обрабатывает его локально в браузере и не передаёт ни в какие внешние сервисы. Чтение буфера выполняется только по явному действию пользователя и только на страницах Яндекс.Директ.

3. Доступ к страницам

Расширение действует только на страницах Яндекс.Директ (direct.yandex.ru, direct.yandex.com и поддомены). Оно не читает и не передаёт содержимое страниц за пределы браузера.

4. Сторонние сервисы

Расширение не использует аналитику, рекламу и не подключает внешние скрипты. Никакие данные не передаются третьим лицам.

5. Изменения

Актуальная версия политики доступна по этой ссылке. При существенных изменениях дата обновления будет изменена.
