Политика конфиденциальности

Расширение: Яркий Директ (Chrome), версия 1.4.1

Дата: 14 августа 2026

1. Назначение расширения

Расширение добавляет в интерфейс Яндекс.Директ и Яндекс.Вордстат: дашборд со сводными графиками, визуализацию данных (полоски в ячейках таблиц отчётов), пресеты отчётов, частотный анализ слов по поисковым запросам, управление минус-словами, панель работы с площадками, инструменты для Wordstat, видео-справку и добавление условий фильтра через контекстное меню. Оно не собирает и не передаёт персональные данные пользователя на наши серверы.

2. Обрабатываемые данные

Содержимое страниц Яндекс.Директ и Вордстата: расширение читает таблицы отчётов, фильтры и связанные элементы интерфейса, чтобы показать гистограммы, анализ запросов и площадок, пресеты и дашборд. Обработка выполняется локально в браузере. Содержимое страниц не отправляется на наши серверы.

Хранилище в браузере (chrome.storage.local): на устройстве пользователя сохраняются только его настройки — привязка столбцов отчёта к цветовым группам, цвета групп, размеры панелей, состояние включения/выключения раскраски; раскладка, фильтры и пресеты дашборда; списки минус-слов (стоп-слов) для частотного анализа; настройки панели Wordstat. Эти данные не отправляются на наши или сторонние серверы.

Синхронизация Chrome (chrome.storage.sync): при включённой синхронизации браузера могут сохраняться настройки включения/выключения модулей расширения (гистограммы, частотный анализ, Wordstat); списки пресетов отчётов и пометки об удалённых заводских пресетах — только для синхронизации между вашими устройствами через аккаунт Google, не на наши серверы.

Локальное хранилище страницы (localStorage): часть настроек гистограмм, панелей и дашборда сохраняется в localStorage на домене Яндекс.Директ для быстрого доступа при работе с отчётами. Данные остаются в браузере пользователя.

CSV-выгрузка отчёта для дашборда: по действию пользователя расширение получает файл статистики из интерфейса Яндекс.Директ (в той же вкладке) и строит графики локально. Файл не передаётся на наши серверы.

Резервная копия настроек: по нажатию кнопки «Выгрузить настройки» в popup расширения пользователь может сохранить JSON-файл на свой компьютер. Загрузка выполняется только по явному выбору файла. Файл не передаётся на наши серверы.

Доступ к буферу обмена (clipboardRead): при нажатии пользователем на кнопку загрузки площадок из буфера в блоке «Анализ площадок» расширение считывает текстовый список площадок из буфера обмена, обрабатывает его локально в браузере и не передаёт ни в какие внешние сервисы. Чтение буфера выполняется только по явному действию пользователя и только на страницах Яндекс.Директ.

Контекстное меню (contextMenus): на страницах Яндекс.Директ доступен пункт «Яркий Директ: добавить в фильтр». По выбору пункта расширение отправляет сообщение только внутри браузера вашей же вкладке с Директом, чтобы заполнить фильтр отчёта; данные не отправляются на наши или сторонние серверы.

3. Доступ к страницам

Расширение действует только на страницах Яндекс.Директ (direct.yandex.ru, direct.yandex.com) и Яндекс.Вордстат (wordstat.yandex.ru). Оно не читает и не передаёт содержимое других сайтов.

4. Сторонние сервисы

Расширение не использует аналитику и рекламу и не загружает внешний JavaScript как код расширения. Все скрипты расширения входят в установочный пакет.

Видео-справка: по запросу пользователя ролики показываются во встроенном iframe проигрывателя Kinescope (kinescope.io). Мы не передаём Kinescope персональные данные, настройки расширения или статистику рекламных кампаний. Воспроизведение подчиняется политике самого проигрывателя.

Никакие данные не продаются и не передаются третьим лицам для рекламы или аналитики.

5. Изменения
