Политика конфиденциальности

Расширение: Яркий Директ (Chrome), версия 1.4.2

Дата: 15 августа 2026

1. Назначение расширения

Расширение добавляет в интерфейс Яндекс.Директ и Яндекс.Вордстат: дашборд со сводными графиками, визуализацию данных (полоски в ячейках таблиц отчётов), пресеты отчётов, частотный анализ слов по поисковым запросам, управление минус-словами, панель работы с площадками, инструменты для Wordstat, видео-справку и добавление условий фильтра через контекстное меню. Содержимое рекламных кабинетов обрабатывается локально и не передаётся на наши серверы.

2. Обрабатываемые данные

Содержимое страниц Яндекс.Директ и Вордстата: расширение читает таблицы отчётов, фильтры и связанные элементы интерфейса, чтобы показать гистограммы, анализ запросов и площадок, пресеты и дашборд. Обработка выполняется локально в браузере. Содержимое страниц и статистика рекламных кампаний не отправляются на наши серверы.

Хранилище в браузере (chrome.storage.local): на устройстве сохраняются настройки (цвета, панели, дашборд, минус-слова, Wordstat), анонимный идентификатор установки и (для сотрудников) служебный токен сессии. Идентификатор установки не связан с аккаунтом Яндекса или email.

Синхронизация Chrome (chrome.storage.sync): при включённой синхронизации браузера могут сохраняться настройки модулей и пресеты отчётов — только для синхронизации между вашими устройствами через аккаунт Google.

Локальное хранилище страницы (localStorage): часть настроек сохраняется в localStorage на домене Яндекс.Директ. Данные остаются в браузере пользователя.

CSV-выгрузка отчёта для дашборда: файл статистики обрабатывается локально и не передаётся на наши серверы.

Резервная копия настроек: JSON-файл сохраняется только на компьютер пользователя по явному действию.

Анонимная статистика использования: на наш API могут отправляться обезличенные события («какая функция открыта / нажата»), случайный идентификатор установки и версия расширения. Не передаются логин Директа, email, тексты объявлений, URL клиентов и содержимое отчётов.

Новости и обратная связь: лента новостей загружается с нашего API. Сообщения обратной связи (текст и необязательный контакт) отправляются на наш API по явному действию в popup.

Режим сотрудника: служебные функции после локального или серверного входа. Для сотрудников доступен AI-прокси на нашем сервере (ключ хранится только на сервере).

Доступ к буферу обмена (clipboardRead): только по явному действию на страницах Яндекс.Директ, локально, без передачи во внешние сервисы.

Контекстное меню (contextMenus): сообщение уходит только во вкладку Директа внутри браузера.

3. Доступ к страницам

Расширение действует на страницах Яндекс.Директ (direct.yandex.ru, direct.yandex.com) и Яндекс.Вордстат (wordstat.yandex.ru). Для новостей, обратной связи, анонимной статистики и служебных функций сотрудника расширение обращается к нашему API https://ryd.avershinin.ru (при локальной разработке — localhost:8000).

4. Сторонние сервисы

Расширение не использует стороннюю рекламную аналитику и не загружает внешний JavaScript как код расширения.

Видео-справка: iframe Kinescope (kinescope.io) по запросу пользователя.

AI для сотрудников: запросы проксируются нашим сервером к OpenRouter. Ключ API не встраивается в расширение. Обычным пользователям AI недоступен.

Данные не продаются и не передаются третьим лицам для рекламы.
